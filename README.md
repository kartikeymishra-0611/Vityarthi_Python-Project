# Vityarthi_Python-Project 

The Student Marks Record Management System is a Python-based project designed to efficiently store, manage, search, update, and delete student records. The system uses file handling and the Pickle module to store student information permanently in a binary file named student.dat.

Each student record contains important details such as Roll Number, Name, and Marks. The project provides a simple menu-driven interface through which the user can perform different operations.

Main Features

Insert Record: Add a new student's roll number, name, and marks.

Display Records: View all stored student records.

Search Record: Find a student using their roll number.

Update Record: Modify the marks of a particular student.

Delete Record: Remove a student's record based on roll number.

Permanent Storage: Records are stored in student.dat using Python's pickle module.


Technologies Used

Programming Language: Python

Modules: os and pickle

File Type: Binary file (student.dat)

Concepts: Functions, dictionaries, loops, conditional statements, file handling, and serialization.


Objective

The main objective of this project is to provide a simple and organized way to manage student marks records while demonstrating practical applications of Python programming and file handling.
